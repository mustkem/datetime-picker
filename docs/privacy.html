Privacy Policy

Last updated: 5 October 2026

DateTime Picker ("the add-on") is a free, open-source Google Sheets add-on. This policy explains what the add-on accesses and what it does with it. In short: it collects nothing.

What the add-on accesses

  • The spreadsheet you are using (spreadsheets.currentonly): only to read the selected cell's existing value and number format, so the picker can open on the current date, and to write the date and time you pick into the cells you selected. It cannot open any other file.
  • The Sheets interface (script.container.ui): to show the add-on menu and dialogs.

What is stored

Your add-on settings (default time zone, date format, clock style and display options) are saved inside the spreadsheet itself using Google Apps Script document properties. Nothing is stored anywhere else.

What is not collected

  • No personal information, email address or account details are collected.
  • No spreadsheet content is sent to the developer or any third party.
  • There are no external servers, analytics, cookies, ads or tracking.

Google API Services User Data Policy

The add-on's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is used only to provide the add-on's user-facing features and is never transferred, sold or used for advertising.

Removing access

Uninstall the add-on from Extensions > Add-ons > Manage add-ons, or remove its access at myaccount.google.com/permissions. Settings saved in a spreadsheet are deleted when that spreadsheet is deleted.

Changes

Any change to this policy will be published on this page with a new date. The full source code is public on GitHub, so you can verify everything above.

Contact

Questions about privacy: open an issue on GitHub Issues.
