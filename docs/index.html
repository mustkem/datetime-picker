Pick a date and a time together in Google Sheets

Sheets only gives you a calendar. DateTime Picker adds the missing time picker, with any time zone, and inserts a real date value into your cells. Free and open source.

Install View source

Features

  • Date and time in one dialog, for one cell or a whole range
  • Any time zone, GMT by default, with the live offset shown
  • Optional conversion to GMT before inserting
  • Insert the current date and time in one click
  • Choose dd/mm/yyyy, mm/dd/yyyy or yyyy-mm-dd and a 12 or 24-hour clock
  • Values stay real dates, so sorting and formulas keep working

Install

Install DateTime Picker from the Google Workspace Marketplace. After installing, open any spreadsheet and go to Extensions > DateTime Picker.

How to use

  1. Select the cells you want to fill.
  2. Open Extensions > DateTime Picker > Pick date and time.
  3. Pick the date, time and time zone, then click Insert.

Support

Found a bug or want a feature? Open an issue on GitHub Issues. Please include what you did, what you expected and what happened.

FAQ

Does it read my data? No. It only writes the value you pick into the cells you select. See the privacy policy.

Why do cells show the zone name? So everyone knows which time zone a value is in. You can turn it off in Settings.

Does it work on mobile? Google does not support add-ons in the Sheets mobile apps yet, so use it in a desktop browser.
